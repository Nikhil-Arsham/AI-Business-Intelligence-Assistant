# AI-Assisted Development Notes

## Tools Used
- ChatGPT
- Python
- Flask
- Pandas
- SQLite
- Streamlit
- Pytest

## AI Assistance
I used ChatGPT to understand the assignment, plan the application architecture, generate and understand code, and debug errors during development.

## Problems Encountered
1. Pytest initially could not find the backend module.
2. One test contained an incorrect expected revenue value.
3. Streamlit displayed an optional email signup prompt.

## Solutions
1. Executed tests using python -m pytest -q from the project root.
2. Corrected the expected test revenue after checking the fixture data.
3. Pressed Enter without entering an email.
